## Phase 1: MVP — 올리고, 보고, 끝

### 목표

**조부모님이 링크를 눌러 손주 사진을 보실 수 있다.** 알림은 아직 없어서 부모가 카톡으로 링크를 한 번 보내드려야 하지만, **이것만으로도 실제로 쓸 수 있는 앱이다.** 카톡에 사진을 우수수 쏟아붓는 일은 이 단계에서 이미 사라진다.

### 기능

- [ ] 부모가 사진 여러 장을 한 번에 업로드 (원본 화질 보존)
- [ ] 업로드 시 화면용 축소본 자동 생성
- [ ] 비밀 링크(`/a/{무작위문자열}`)로 접속
- [ ] 암호 4자리 입력 → 맞으면 30일간 안 물어봄
- [ ] 사진을 **찍은 날짜순**으로 최신부터 표시
- [ ] 사진 탭하면 원본 크게 보기
- [ ] 사진마다 한 줄 메모 붙이기
- [ ] 조부모님 기준 화면 (큰 글씨, 큰 버튼)
- [ ] **링크 재생성** — 링크가 새어나갔을 때 새 주소 발급, 옛 링크 즉시 무효
- [ ] 검색엔진 완전 차단
- [ ] 실제 인터넷 주소로 배포

### 데이터

- `albums`, `photos` (2개만. `subscribers`는 Phase 2)

### 인증

- **로그인 없음.** 앨범별 암호 + 브라우저 쿠키(30일)
- 암호는 반드시 해시로 저장

### "진짜 제품" 체크리스트

- [ ] 실제 DB 연결 (목업 데이터 ❌)
- [ ] 실제 암호 검증 (코드에 박아넣은 암호 ❌)
- [ ] 실제 서버에 배포 (localhost ❌)
- [ ] **조부모님 폰으로 실제 접속해서 사진이 보인다**
- [ ] 구글에서 검색해도 안 나온다
- [ ] 코드를 GitHub에 그대로 올려도 가족 정보가 노출되지 않는다

## Phase 2: 알림 (문자 기본 · 텔레그램 선택)

### 전제 조건

- Phase 1이 실제 주소로 배포돼 안정적으로 돌아가는 상태
- **⚠️ 시작 전 반드시 확인**: 문자(SMS) API를 개인 명의로 쓸 수 있는지. 막히면 텔레그램을 기본으로 승격한다

### 목표

부모가 사진을 올리면 **가족에게 알림이 자동으로 간다.** 이제 부모는 카톡을 한 번도 안 보내도 된다. 이 단계에서 원래 목표가 완성된다.

**가족마다 받는 방법이 다를 수 있다.** 어머님은 문자, 동생은 텔레그램. 그래서 채널을 고를 수 있게 만든다.

### 기능

- [ ] 알림 받을 가족 등록/수정/삭제 (이름 + 채널 + 주소)
- [ ] **채널 선택** — 가족마다 문자 또는 텔레그램 중 하나
- [ ] 사진 업로드 시 자동 발송 (링크 포함)
- [ ] 알림 끄기/켜기
- [ ] **묶어서 보내기** — 사진 10장을 올려도 알림은 1통만. (안 그러면 조부모님 폰이 10번 울리고, 문자 요금도 10배)

### 채널별 특성

| | 받는 분 부담 | 비용 | 걸림돌 |
|---|---|---|---|
| **문자** (기본) | 없음 — 이미 문자는 보심 | 건당 20원 안팎 | ⚠️ 개인 명의 발송 가능 여부 미확인 |
| **텔레그램** (선택) | 앱 설치 + 봇에게 `/start` 1회 | 0원 | 어르신께 낯선 앱. 폰 바꾸면 재설정 |

> **만들다 보면 순서가 뒤집힐 수 있다.** 텔레그램이 문자보다 만들기 쉽고 공짜다. 문자가 개인 명의로 막히면 텔레그램이 기본이 된다. 이 판단은 Phase 2 시작 시점에 한다.

### 추가 데이터

- `subscribers` 테이블

### 통합 테스트

- Phase 1 기능이 여전히 정상 동작하는지 확인
- 문자가 실제로 도착하는지 **본인 번호로 먼저 테스트** (가족에게 테스트 문자 보내지 말 것)

### 주의사항

- 문자는 **건당 요금이 발생한다** (20원 안팎). 코드 오류로 반복 발송되면 요금이 새어나간다 → 발송 횟수 상한을 반드시 걸 것
- 개인정보(전화번호)를 다루기 시작하는 단계다

## Phase 3: 영상 + 오픈소스 공개

### 전제 조건

- Phase 1 + 2가 가족들 사이에서 실제로 몇 달 굴러간 상태

### 목표

영상도 올릴 수 있게 하고, 코드를 공개해서 다른 부모들도 각자 설치해 쓸 수 있게 한다.

### 기능

- [ ] 짧은 영상 업로드 (길이 상한 권장 — 예: 1분)
- [ ] 영상 자동 변환 (폰마다 재생되게)
- [ ] 설치 설명서 작성 (비개발자도 따라 할 수 있는 수준)
- [ ] `.env.example` 정비
- [ ] **비밀 노출 전수 점검** — 커밋 기록까지 전부 뒤져서 가족 정보·키가 없는지 확인
- [ ] 라이선스 결정 후 GitHub 공개

### 주의사항

- **영상은 사진의 수백 배 용량이다.** 무료 10GB가 금방 찬다. 비용이 실제로 발생하기 시작하는 지점
- **공개 전 비밀 점검은 한 번 실수하면 되돌릴 수 없다.** 이미 올라간 커밋 기록은 지워도 남는다. 이 단계는 절대 서두르지 말 것

## Phase 로드맵 요약

| Phase | 핵심 기능 | 이게 끝나면 | 상태 |
|-------|----------|------------|------|
| **Phase 1 (MVP)** | 업로드 + 링크·암호 열람 + 메모 + 링크 재생성 | 카톡에 사진 쏟아붓기가 사라짐 (링크는 수동 전송) | 시작 전 |
| **Phase 2** | 알림 (문자 기본 · 텔레그램 선택) | 카톡을 아예 안 보내도 됨 — **원래 목표 달성** | Phase 1 완료 후 |
| **Phase 3** | 영상 + 오픈소스 공개 | 남들도 각자 설치해서 씀 | Phase 2 완료 후 |

> **기간은 일부러 안 적었습니다.** 곰곰님이 직접 코딩하시는 게 아니라 제가 만들고, 실제로 돌려보고 고치는 시간이 얼마나 걸릴지는 해봐야 압니다. 추측으로 "2주" 같은 숫자를 적어두면 그게 약속처럼 굳어져서 나중에 서로 곤란해집니다.
