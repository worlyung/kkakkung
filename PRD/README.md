## ⚠️ 미결 사항 — 개발 전에 정해야 함

**Phase 1 시작 전**
- [ ] **부모용 암호와 조부모용 암호를 나눌지** — 지금 구조는 앨범당 암호 1개. 나누려면 데이터 구조에 열 하나 추가
- [ ] **조부모님이 실제로 쓰시는 폰과 브라우저** — 테스트 대상을 정해야 함
- [ ] **도메인을 살지** — 무료 주소(`~.vercel.app`)로 갈지, 짧은 주소를 살지 (연 1~2만 원)
- [ ] **삭제 방식** — 실수로 지웠을 때 복구할 휴지통을 둘지

**Phase 2 시작 전 (반드시)**
- [ ] **문자(SMS)를 개인 명의로 보낼 수 있는지 확인** — 카카오 알림톡이 사업자등록 필수인 건 확인됐지만, **일반 문자 API를 개인이 쓸 수 있는지는 아직 확인 안 했습니다.** 막히면 **텔레그램을 기본으로 올립니다** (공짜 + 사업자등록 불필요)

**~~사진 백업~~ — 해결됨 (2026-07-16)**
- [x] 원본은 **구글포토에 백업**하고 있음. R2는 "가족 보여주는 창구", 구글포토가 "진짜 금고". R2 계정 사고가 나도 원본은 안전 → 유일본 위험 없음

**Phase 3 전**
- [ ] **오픈소스 라이선스 결정** (MIT / AGPL 등)
- [ ] **사진 중복 업로드 처리** — 같은 사진 두 번 올리면 두 장. 없어도 동작엔 문제 없음
