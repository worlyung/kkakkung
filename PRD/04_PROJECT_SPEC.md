# photo_heaven — 프로젝트 스펙

> **AI에게 코드를 시킬 때마다 이 문서를 함께 보여주세요.**
> 여기 적힌 "절대 하지 마"는 협상 대상이 아닙니다.

## 기술 스택

| 영역 | 선택 | 왜 골랐나 |
|------|------|----------|
| 프레임워크 | **Next.js 15** (App Router, TypeScript) | Vercel 무료 배포가 클릭 몇 번. AI 코딩 예제가 압도적으로 많아 성공률이 높다 — 곰곰님이 코드를 직접 못 고치므로 이게 결정적 |
| 스타일링 | **Tailwind CSS** | 사실상 표준. 조부모용 큰 글씨/버튼 조정이 쉽다 |
| 사진 저장 | **Cloudflare R2** | **10GB 무료 + 나가는 트래픽 완전 무료.** 조부모님이 사진을 아무리 많이 봐도 요금이 0원. 다른 저장소(AWS S3 등)는 이 트래픽에서 돈을 뜯는다. 초과해도 100GB에 월 2천 원 수준 |
| DB | **Supabase** (PostgreSQL) | 무료 티어로 충분(테이블 3개, 사진 몇 천 장). Next.js 연동 예제가 많다. 나중에 자기 서버로 옮길 수 있어 오픈소스화에 유리 |
| 배포 | **Vercel** | Next.js 만든 회사. 무료. 깃허브에 올리면 자동 배포 |
| 인증 | **없음** (앨범 암호 + 서명된 쿠키) | 로그인을 없애는 게 이 제품의 존재 이유. Supabase Auth를 **쓰지 않는다** |
| 세션 유지 | **슬라이딩 30일** — 볼 때마다 30일 연장 (미들웨어에서 쿠키 재발급). **D단계에서 구현** | 지금은 처음 넣은 날부터 고정 30일이라, 매일 봐도 30일째 풀린다. 조부모님이 자주 보시면 사실상 재입력 없게 |
| 알림 — 기본 (Phase 2) | **문자 (SMS)** — 솔라피 등 | 조부모님이 아무것도 안 깔아도 됨. ⚠️ 개인 명의 사용 가능 여부 **미확인** |
| 알림 — 선택 (Phase 2) | **텔레그램 봇** | 공짜, 사업자등록 불필요, 해외 사용자도 씀. 단 받는 분이 앱 설치·봇 시작을 하셔야 함 |

> **트레이드오프 기록**: 서비스가 Vercel·Supabase·Cloudflare 3곳에 걸쳐 있다. 오픈소스로 공개하면 설치하는 사람이 3곳에 가입해야 해서 진입 장벽이 된다. 그럼에도 이 조합을 고른 건 **R2의 트래픽 무료**가 사진 앱에서 너무 크기 때문이다. Phase 3에서 도커 한 방 설치 옵션을 검토한다.

## 절대 하지 마 (DO NOT)

> AI에게 코드를 시킬 때 이 목록을 반드시 함께 공유하세요.

- [ ] **API 키·암호를 코드에 직접 쓰지 마.** 전부 `.env.local`
- [ ] **곰곰님 가족 정보를 코드·주석·커밋 메시지·문서·테스트 데이터에 넣지 마.** 아기 이름, 전화번호, 실제 링크 주소, 암호 전부. **이건 오픈소스로 공개할 코드다.** 예시가 필요하면 `아기이름`, `010-0000-0000` 같은 가짜를 써라
- [ ] **R2 버킷을 공개(public)로 열지 마.** 사진은 서명된 URL로만 내보낸다. 공개 버킷은 주소만 알면 누구나 아기 사진을 본다는 뜻이다
- [ ] **검색엔진에 노출되게 하지 마.** 모든 페이지에 `noindex`, `robots.txt`로 전면 차단
- [ ] **암호를 평문으로 저장하지 마.** 반드시 해시(bcrypt 등)
- [ ] **원본 사진을 지우거나 덮어쓰지 마.** 축소본은 따로 만든다. 원본은 건드리지 않는다
- [ ] **로그인·회원가입 시스템을 만들지 마.** 시키지 않았고, 이 제품이 없애려는 바로 그것이다
- [ ] **목업·하드코딩 데이터로 "완성됐다"고 하지 마.** 실제 DB, 실제 저장소, 실제 배포 주소로 확인한 것만 완료다
- [ ] **테스트 없이 배포하지 마**
- [ ] **package.json의 기존 의존성 버전을 임의로 바꾸지 마**
- [ ] **알림을 상한 없이 호출하지 마** (Phase 2). 무한 루프 한 번이면 문자 요금이 새고, 조부모님 폰이 밤새 울린다
- [ ] **알림 채널을 코드에 하드코딩하지 마.** 문자·텔레그램을 갈아끼울 수 있게 발송 함수를 분리할 것. 문자가 막히면 텔레그램이 기본이 된다

## 항상 해 (ALWAYS DO)

- [ ] **조부모님 기준으로 만들어라** — 글자 18px 이상, 버튼 44px 이상, 한 화면에 할 일 하나. 이게 이 제품의 전부다
- [ ] **모바일 우선.** 조부모님은 폰으로 보신다. PC는 부수적
- [ ] **원본 + 화면용 축소본을 둘 다 보관.** 목록은 축소본으로 빠르게, 탭하면 원본
- [ ] **사진 정렬은 찍은 날짜 기준.** 없으면 올린 날짜로 대체
- [ ] **`.env.example`을 항상 최신으로 유지** (값은 비우고 이름만)
- [ ] **에러 메시지는 쉬운 말로.** "500 Internal Server Error"가 아니라 "사진을 올리지 못했어요. 다시 시도해주세요"
- [ ] **변경하기 전에 계획을 먼저 보여줘**
- [ ] **완료 보고 전에 실제로 돌려보고 화면을 보여줘.** 추측으로 "됐습니다" 금지

## 배포 방법

1. GitHub에 올린다 (`.env.local`이 `.gitignore`에 있는지 **반드시 먼저 확인**)
2. Vercel에 GitHub 저장소를 연결한다
3. Vercel 대시보드에 환경변수를 입력한다 (아래 표)
4. 자동 배포된다. 이후 코드를 올릴 때마다 자동 반영

## 환경변수

| 변수명 | 설명 | 어디서 발급 |
|--------|------|------------|
| `NEXT_PUBLIC_SUPABASE_URL` | DB 주소 | supabase.com 프로젝트 설정 |
| `SUPABASE_SERVICE_ROLE_KEY` | DB 전체 권한 키. **절대 브라우저에 노출 금지** | supabase.com 프로젝트 설정 |
| `R2_ACCOUNT_ID` | Cloudflare 계정 번호 | dash.cloudflare.com |
| `R2_ACCESS_KEY_ID` | R2 접근 키 | Cloudflare R2 → API 토큰 |
| `R2_SECRET_ACCESS_KEY` | R2 비밀 키 | Cloudflare R2 → API 토큰 |
| `R2_BUCKET` | 사진 담을 통 이름 | 직접 지정 |
| `SESSION_SECRET` | 쿠키 위조 방지용 무작위 문자열 | 직접 생성 (긴 무작위 문자) |
| `SMS_API_KEY` *(Phase 2)* | 문자 발송 키 | 솔라피 등 (업체 미정) |
| `SMS_SENDER` *(Phase 2)* | 발신 번호 | 통신사에 등록한 본인 번호 |
| `TELEGRAM_BOT_TOKEN` *(Phase 2)* | 텔레그램 봇 열쇠 | 텔레그램에서 `@BotFather`에게 발급받음 (무료, 1분) |

> `.env.local`에 저장. **절대 GitHub에 올리지 마세요.** 한 번 올라가면 지워도 커밋 기록에 남습니다.
